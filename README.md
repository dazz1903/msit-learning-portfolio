## Learning focus

These are areas to document as evidence becomes available, rather than a list of verified competencies:

- **Software engineering:** problem decomposition, maintainable code, debugging, and testing.
- **DevOps:** version control, automation, repeatable environments, and delivery practices.
- **Professional practice:** technical documentation, constructive review, and reflection.

A skill will be presented as demonstrated only when linked to specific work and evidence. Tools and languages will be listed against the projects that actually use them.

## How to read the evidence

Project pages distinguish independent work, coursework, and team contributions. Assessment records distinguish instructor-assigned grades from automated platform scores. Feedback records connect the original observation to a concrete improvement and its verification.

No aggregate performance statistics will be published until authentic, comparable results are available. This is a personal learning portfolio, not an official MSIT transcript or endorsement.
