## How to interpret this portfolio

The records were collected from Codio's general instructor Comments on 9 November 2026, for **Software Engineering DE / Mandatory**. Grades retain the value labelled **Grade**, without assuming a denominator or converting to percentages. This selected set is not a complete course transcript.

Feedback summaries are labelled as paraphrases; quotations are exact selected excerpts. Later fixes, independent code execution, and complete inline reviews are not yet verified. This is a personal learning portfolio, not an official transcript or endorsement.
